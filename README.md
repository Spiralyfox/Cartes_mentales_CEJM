# Cartes mentales CEJM

Des cartes mentales de CEJM (BTS SIO) au format **draw.io** (`.drawio`).
Chaque fichier s'ouvre et se modifie sur [draw.io](https://draw.io) (aussi appelé diagrams.net).

---

## 1. Télécharger les cartes

### Tout le dépôt d'un coup

1. En haut de cette page, cliquez sur le bouton vert **`< > Code`**.
2. Dans le menu, cliquez sur **Download ZIP**.
3. Ouvrez le fichier `.zip` téléchargé, puis **Extraire tout** (clic droit > Extraire tout).

Vous obtenez un dossier contenant tous les fichiers `.drawio`.

### Un seul fichier

1. Dans la liste des fichiers, cliquez sur la carte qui vous intéresse (par exemple `THEME4_CHAP1_MANA.drawio`).
2. GitHub affiche un aperçu. En haut à droite de cet aperçu, cliquez sur le bouton de téléchargement **Download raw file** (l'icône avec une flèche vers le bas).

---

## 2. Ouvrir une carte dans draw.io

1. Allez sur [https://draw.io](https://draw.io).
2. Cliquez sur **Fichier > Ouvrir depuis > Périphérique** (ou « Open Existing Diagram » au premier lancement).
3. Sélectionnez le fichier `.drawio` téléchargé.
4. La carte s'ouvre : vous pouvez la consulter, la modifier et l'exporter (Fichier > Exporter en PNG, PDF, etc.).
