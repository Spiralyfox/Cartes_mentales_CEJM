# Cartes mentales CEJM

Pour ouvrir une des cartes mentales, téléchargez là depuis ce dépôt <br>
Rendez vous sur https://draw.io <br>
Cliquez sur Fichier > Ouvrir depuis > Périphérique <br>
Sélectionnez le fichier que vous venez de télécharger <br>
La carte mentale s'ouvrira sur le site outil draw.io <br>
